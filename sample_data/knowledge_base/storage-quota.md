# Resolving storage quota errors

An upload may fail when a workspace reaches its storage allowance. Confirm the affected workspace and compare its reported usage with the subscription's storage limit. Check whether the error is limited to one file or affects every upload.

## Review usage safely

Ask an authorized workspace administrator to review large or obsolete content and the product's retention settings. Deleting files can be irreversible or affect collaborators, so support must not delete customer data without explicit authorization and the approved workflow. The customer should preserve anything they may need before removing content.

## If usage appears incorrect

Record the displayed usage, approximate time, affected workspace, and safe error details. Check for active service incidents and allow for any documented usage recalculation. If the quota is wrong or uploads remain blocked below the limit, escalate to the storage support team.
